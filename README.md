<h1 align="center">SalesScope Dashboard</h1>

<p align="center">
  Um painel de Business Intelligence (BI) moderno e responsivo, desenvolvido com Next.js e Tailwind CSS, focado em visualizações de dados comerciais.
  <br />
  Este projeto visa fornecer insights estratégicos para equipes de vendas, utilizando tecnologias web.
</p>

## 📋 Principais Funcionalidades

- 📊 Visualização de métricas (simuladas) de vendas
- 📈 Dashboards personalizados com filtros dinâmicos
- 🔐 Autenticação de usuários e controle de acesso utilizando Firebase
- 📁 Exportação de relatórios em diversos formatos

## 🧪 Testes

Para executar os testes, utilize o seguinte comando no terminal:

No bash:
npm run test

yarn test

## 📦 Instalação

Siga os passos abaixo para rodar o projeto localmente:

### Clone o repositório
git clone https://github.com/JoaoGW/SalesScope.git

### Acesse o diretório do projeto
cd SalesScope

### Instale as dependências
npm install
ou
yarn install

### Inicie o servidor de desenvolvimento
npm run dev
ou
yarn dev
